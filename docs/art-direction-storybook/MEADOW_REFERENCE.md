# Reference grass revision — 2026-10-13

The current user request asks for grass colors, painted ground and upright boundary growth closer to `artbook-style.png`. This supersedes the earlier opt-in-only grass scope. The source game's normal startup now enables the meadow across Alderwake and Moonwood. Old A/B/C and depth launch arguments retain their earlier local appearance. `--meadow=off` selects the original no-pilot ground. Existing Windows packages were not rebuilt.

## Appearance

- New generated ground albedo uses fine blade strokes and quiet olive patches. Two world-space scales reduce obvious repetition; imported mipmaps and a modest positive sampling bias stabilize distant detail.
- A shared visual grass mask rounds and scallops path/stone/sand shoulders without moving terrain, water, collision or navigation. The same albedo recipe meets both sides of the join.
- Actual low foundation vertices determine building/wall contact outlines. A narrow shaded band and irregular upright pockets attach growth to those visible bases, with doorway and portal exclusions.
- Deterministic grass includes 1,386 foundation, 601 path-bank, 467 tree-root and 879 field clumps. Total: 3,333 clumps, 78,060 triangles, 58 spatial chunks, one opaque material. Grass casts no extra shadows and has no physics/navigation nodes. Blade normals face upward on both sides so back faces do not become black cutouts.

The source image is `art/source/storybook/grass-meadow-albedo-v3.png`; runtime uses `game/assets/environment/storybook/grass-meadow-albedo-v3.png`. Actual dimensions are 1254×1254 (the tool returned this size despite the 1024 request). Both files preserve generated bytes.
